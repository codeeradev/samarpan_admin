Website Update Requirements Document
Document Title: Website Update Requirements
Purpose: Consolidate the handwritten website update requirements into clear, actionable development tasks.
1. Right-to-Left Scrolling
Requirement:
Implement a right-to-left (RTL) scrolling mechanism for the relevant website section/carousel.
Expected Behaviour:
Content should move smoothly from right to left.
Include appropriate navigation controls where required.
Ensure the scrolling works correctly on desktop and mobile devices.
2. Remove Tile/Box Outlines
Requirement:
Remove the visible outline/border around tiles or boxes.
Expected Behaviour:
Tiles should appear clean and borderless.
Remove unnecessary box outlines from the UI.
Maintain proper spacing and visual hierarchy after removing the borders.
The change should be reflected consistently across the website.
3. Top Panel / First Page Slider
Requirement:
Add/display a panel at the top of the first page with a slider.
Expected Behaviour:
The panel should appear at the top of the first/home page.
It should support multiple slides.
Users should be able to navigate between slides.
Slider should be responsive across desktop, tablet and mobile.
Navigation arrows/controls should be provided where applicable.
4. Export Medical Services Section
Requirement:
Update the Export Medical Services section, specifically the hospital/nursing-related content.
Expected Action:
Review the existing hospital/nursing content.
Replace/update the current information as required.
Ensure the updated content follows the website's existing design and formatting.
Note: The exact wording after “hospital/…” in the handwritten note is not completely legible, so the final content should be confirmed before implementation.

Apply the same typography standards within the Admin Panel.
